CELPIP Speaking · Task 8

Describing an Unusual Situation

Describe an image in which something is out of place or strange, explaining what is happening, why it seems unusual, and what might occur next.

30 s preparation 60 s response SelfPIP study guide
Golden rule: Set the scene normally, then focus everything on what is wrong — the unusual detail is the whole point of this task.
1 What this task is

What Is This Task?

In Task 8 the screen shows a photograph where something does not belong — a bathtub full of fruit, a desk in the middle of a lake, snow indoors. You describe the scene, explain why it is unusual, and speculate about what is going on.

This task combines description and prediction: WHAT you see, WHY it is strange, and WHAT might be happening or happen next. The strange element is your material — name it precisely, contrast it with what you would normally expect, then build plausible explanations around it.

Preparation

30 seconds — find the odd element and one normal contrast for it.

Response

60 seconds — scene → odd detail → why → what might be going on.

Skill mix

description + explanation + speculation, all in one response.

Official format vs SelfPIP advice: The task description and timings above are official CELPIP format information. The framework, language banks, traps, practice prompt, and model response on this page are SelfPIP study guidance — not official CELPIP material, and not a scoring rule.
2 How to answer

How to Answer This Task

The hub's CLEAR framework structures the strangeness so the listener feels it too:

Context → Entities → Action → Result
  1. Preparation (30 s): Identify where the photo is set, what the strange element is, and what SHOULD normally be there instead — that contrast is your material.
  2. Context (≈10 s): Frame the setting normally first: "This photo appears to be taken inside an ordinary kitchen..." — the normal frame makes the odd part land.
  3. Entities (≈15 s): List what's present — people and objects — the same way you would in Task 3, so the listener can picture the baseline.
  4. Action (≈15 s): What's going on right now, present continuous — including what the people are doing about the strange thing (or ignoring it).
  5. Result (≈20 s): Deliver the unusual part explicitly — what makes this strange, what you'd expect instead — plus a short speculation: what might be going on or what happens next.
Timing reality: The unusual detail must arrive by the 25–30 second mark. Don't spend the whole minute on normal scene-setting — the strangeness is what you're scored on describing.
3 Useful language

Useful Language

Setting the normal context
  • This looks like an ordinary... / At first glance, it's a typical...
  • The setting appears to be...
  • You'd expect to see... here, and in some ways you do.
Flagging the unusual part
  • What immediately stands out is...
  • The strange thing is that... instead of...
  • For some reason, there's a... right in the middle of...
  • What makes this unusual is the contrast between... and...
Contrast language
  • whereas / while normally...
  • You'd expect X, but clearly Y...
  • rather than..., they've... / instead of..., it's...
Speculating (what is going on)
  • I'd imagine this is some kind of...
  • My guess would be that they're preparing for...
  • This might be an art project / a film set / an advertisement.
  • Something tells me this won't stay this way for long.
Stress these words

the ODD noun and its normal counterpart — "a BATHTUB full of ORANGES" is the whole performance.

Tone

lightly puzzled, never alarmed — you're describing oddity, not danger.

4 Common traps

Common Traps

⚠ Trap 1 — Doing Task 3 again

How it feels: A perfectly orderly description of every object — that never notices the cow sitting in the bathtub.

Instead: Find the odd element FIRST in prep, then build the whole response so it points at that contrast.

⚠ Trap 2 — "It's weird" with no description

How it feels: "This is so strange! I've never seen anything like it." — emotion, but the listener can't picture WHAT is strange.

Instead: Name the anomaly precisely, then contrast: "There's a bathtub full of oranges — where you'd normally find bath water."

⚠ Trap 3 — Skipping the "why"

How it feels: You flag the oddity and move on — no explanation, no speculation; half the response time unused.

Instead: Always speculate: an art project, an advertisement, a festival? Give a guess AND a reason for it.

⚠ Trap 4 — Treating it as absurd

How it feels: Laughing disbelief — "This is completely crazy, who would do this?!" — sounds stunned, not descriptive.

Instead: Stay a calm observer: mildly puzzled, analytical, curious. The tone itself should sound like a 10-scorer.

5 Practice

Original Practice Prompt

Original SelfPIP prompt — not an official CELPIP question

Task: Describe this image, explain why it is unusual, and say what you think might be going on. (30 s preparation → 60 s response)

How to use this prompt: Time yourself so the unusual element lands by 25–30 seconds. Then add one speculation with a reason — "This might be a team-building exercise, since offices sometimes..." — before you close.
6 Model response

Annotated Model Response

"This photo appears to be taken inside an ordinary corporate meeting room — you know the type: a big grey table, a wall-mounted screen in the corner, a window with blinds on the left, and a red fire-extinguisher sign near the door. A man in a suit is standing to the right of the table, gesturing towards it like he's presenting something.

What immediately stands out is that there's a full camping tent pitched right on top of the conference table — orange canvas, zipped-open flap and all — where you'd normally find laptops and coffee cups.

So something unusual is definitely going on here. My guess would be that this is some kind of team-building event or a company product launch — perhaps an outdoor-gear company unveiling a new tent to its sales team — because a man is presenting it formally, which you wouldn't do for a joke. Whatever the reason, I have a feeling the next few minutes involve a lot of photos and somebody giving a speech."

Why this works

ContextBuilds the NORMAL frame first — table, screen, blinds, sign — so the oddity has something to violate.
EntitiesObjects and the presenter named with positions — the listener can sketch the room before the twist arrives.
Action"gesturing... like he's presenting" — present continuous keeps the scene alive and sets up the speculation.
ResultThe anomaly lands mid-response, contrasted against "where you'd normally find laptops" — then TWO reasoned guesses close it out.
7 Self-check

Self-Check Before You Record

Task 8 — Describing an Unusual Situation

  • Did I set the normal scene BEFORE flagging the odd part?
  • Did the unusual element land by 25–30 seconds?
  • Did I name exactly WHAT is strange and what's normal instead?
  • Did I speculate — what's going on or what happens next?
  • Did I give a reason for my speculation?
  • Did I stay a calm observer instead of acting shocked?
0 unchecked

Mindset

Strange is your material — the weirder the picture, the more you have to work with. Stay curious rather than shocked, and the response sounds analytical: exactly the register that scores.
