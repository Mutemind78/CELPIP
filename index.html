What is CELPIP?

The test

CELPIP — the Canadian English Language Proficiency Index Program — is a Canadian English test accepted by Immigration, Refugees and Citizenship Canada (IRCC) for permanent residence, citizenship and professional designation decisions.

Four modules

Listening, Reading, Writing and Speaking — completed on a computer at a test centre in one appointment. Each module uses a fixed set of part and task types, and every one of them is explained in the study sections below.

Two versions

CELPIP-General covers all four modules and is used for permanent residence and professional designations. CELPIP-General LS covers only Listening and Speaking — the test most Canadian citizenship applicants take.

Your score

Each module is reported as a Canadian Language Benchmark (CLB) level from 1 to 10. Immigration programs, employers and colleges each set the CLB level they require — SelfPIP helps you train toward yours.
