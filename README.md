# SelfPIP — CELPIP Study Companion

SelfPIP is a free, independent web resource designed to help CELPIP test takers understand the test, build their English skills, learn practical strategies, and practice each section.

## 🌐 Overview

SelfPIP provides a simple, accessible study experience covering:

* 🎧 Listening
* 📖 Reading
* ✍️ Writing
* 🗣️ Speaking
* 📚 Language
* 🧩 Practice & Resources

The goal is to keep CELPIP preparation **simple, practical, and accessible from any device**.

## ✨ Features

### Test Preparation

* CELPIP test format and structure
* Section-by-section explanations
* Task-specific strategies
* Time-management guidance
* Common mistakes and traps

### Listening

Covers all six Listening parts:

1. Listening to Problem Solving
2. Listening to a Daily Life Conversation
3. Listening for Information
4. Listening to a News Item
5. Listening to a Discussion
6. Listening to Viewpoints

Includes strategies, note-taking techniques, signal words, common traps, and original practice activities.

### Reading

Covers:

* Reading Correspondence
* Reading to Apply a Diagram
* Reading for Information
* Reading for Viewpoints

### Writing

Covers:

* Task 1 — Writing an Email
* Task 2 — Responding to Survey Questions

Includes organization, useful sentence patterns, vocabulary, connectors, and practical strategies.

### Speaking

Covers all eight CELPIP Speaking tasks:

1. Giving Advice
2. Talking about a Personal Experience
3. Describing a Scene
4. Making Predictions
5. Comparing and Persuading
6. Dealing with a Difficult Situation
7. Expressing Opinions
8. Describing an Unusual Situation

### Language

The Language section provides additional English support through:

* Grammar
* Vocabulary Banks
* Connectors
* Canadian English / Pronunciation
* CELPIP Sentence Patterns

### Practice & Resources

The project is designed to support:

* Quick Practice
* Skill Practice
* Timed Practice
* Self-Review
* Curated learning resources
* Future AI-powered writing and speaking feedback

## 🎯 Project Goals

SelfPIP is built around five main goals:

1. **Understand the Test** — Learn how CELPIP is structured.
2. **Learn Strategies** — Understand how to approach different tasks.
3. **Build English Skills** — Improve grammar, vocabulary, connectors, and sentence structure.
4. **Practice Skills** — Apply what you learn through original practice.
5. **Review & Improve** — Use checklists, explanations, and feedback to identify areas for improvement.

## 🛠️ Technology

SelfPIP is intentionally lightweight and uses a simple front-end architecture.

* HTML5
* CSS3
* JavaScript
* LocalStorage for selected preferences/checklists
* Netlify for deployment

There is currently **no database, login system, or user account requirement**.

## 📱 Responsive Design

SelfPIP is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📟 Tablet

The interface aims to remain simple and readable regardless of screen size.

## 🌙 Theme Support

The website includes a light/dark theme system with user preference persistence.

## 🚀 Running Locally

No build system is required.

1. Clone or download the repository.
2. Open the project in VS Code.
3. Open `index.html` in a browser, or use a local development server such as VS Code Live Server.
4. Make changes to the HTML, CSS, or JavaScript files.
5. Refresh the browser to see the changes.

## 🌐 Deployment

The project can be deployed as a static website using Netlify or another static hosting provider.

## 📌 Content Policy

SelfPIP aims to provide original educational material and practical explanations.

Official CELPIP information should be checked against the official CELPIP website because test formats, policies, and requirements can change.

Official CELPIP questions and copyrighted preparation materials are not reproduced as original SelfPIP content.
